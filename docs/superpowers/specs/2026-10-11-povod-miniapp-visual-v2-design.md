# «Повод» Mini App — визуальная система v2 и навигация

Дата: 2026-10-11. Заменяет §9 «Стеклянный вечер», каркас и вкладки из §8 и
тон текстов §10 спеки `2026-10-10-povod-miniapp-guest-design.md`. API,
данные, оплата, пограничные случаи и доступность (§4–7, §11–12) — без
изменений, если ниже не сказано иначе.

## 1. Цель и критерии

Сделать гостевой Mini App «как Netflix / Apple / Кинопоиск»: чёрный фон,
крупные яркие постеры несут цвет, интерфейс монохромный и спокойный.

Готово, когда:
- главный экран читается как витрина: billboard + ряды постеров;
- каждый экран события «окрашен» своей афишей (ореол);
- билет выглядит бумажным — перфорация, вырезы, корешок с QR;
- все тексты на «ты» в одном голосе;
- контраст и тап-зоны по-прежнему проходят WCAG AA / ≥44 px.

## 2. Решения владельца (сессия 2026-10-11)

| Тема | Решение |
|---|---|
| Настроение | Netflix / Apple / Кинопоиск; чёрный фон, яркие постеры, скругления |
| Тема | только тёмная, `colorScheme` Telegram игнорируем |
| Цвет | акцент берётся из афиши: ореол сверху экрана (вариант А) |

| Над меню | в день события — пилюля «Сегодня 23:00 · …», тап открывает QR |

## 3. Токены

### Цвет

| Роль | Значение |
|---|---|
| bg | #000000 |
| surface 1 / 2 / 3 | #0E0D10 / #151316 / #1F1C22 |
| text 1 / 2 / 3 | #FFFFFF / #B8B2B5 / #8F898C |
| border | rgba(255,255,255,.10) |
| glass | rgba(28,26,30,.72) + blur 20 px saturate 1.4 |
| glass-border | rgba(255,255,255,.12) |
| button primary / on-primary | #FFFFFF / #000000 |
| button secondary | glass |
| success / error / warning | #5FD0A8 / #FF7A7A / #FFC857 |
| tabbar | #151316, обводка rgba(255,190,170,.16) |
| ticket paper / ink / muted / perforation | #F4F1EA / #141414 / #6B665E / #C9C3B8 |

**Цвет афиши (`poster`).** Для каждого события — один цвет:
1. поле `accent_color` события, если задано организатором;
2. иначе — средний насыщенный цвет постера (canvas 32×32, отбрасываем
   пиксели с яркостью <15% и >90%, берём медиану по hue);
3. иначе — цвет по хэшу названия из 8 проверенных (как в старой спеке).

Цвет нормализуется в HSL: S ∈ [45%, 80%], L ∈ [45%, 60%]. Используется
только в ореоле, статус-пилюлях и фоне стрипа «идут +N» — **никогда как
фон под текстом и не в кнопках**, поэтому контраст от постера не зависит.
Исключение — строка «когда» на афише Дома: текст — 25% цвета на белом
(≥ 5:1 даже над белым участком фото под скримом), точка — полный цвет.

**Ореол.** `radial-gradient(130% 55% at 50% 0%, poster/.55 → transparent 70%)`
поверх bg, высотой ~60% экрана, `position: fixed` за контентом. Смена
события — переход цвета 400 мс. На Доме, в Кабинете и Избранном
ореола нет — верх экрана чёрный.

### Типографика

Wix Madefor Display 700 — заголовки; Wix Madefor Text 400/500 — текст,
метки, цифры. Self-host woff2 (кириллица+латиница), `font-display: swap`.
Регистр обычный, без капса.

| Стиль | Размер/строка | Шрифт |
|---|---|---|
| billboard (название на афише Дома) | 26/28, длинное — 22/24, letter-spacing −0.02em | Display 700 |
| h1 (шапка события) | 28/32 | Display 700 |
| h2 (заголовок ряда) | 20/24 | Display 700 |
| h3 (карточка) | 16/20 | Display 700 |
| body | 15/22 | Text 400 |
| body-s | 13/18 | Text 500 |
| meta («Киновечер · 18+») | 13/16 | Text 500, text 2 |
| button | 16/20 | Text 500 |
| price | 17/22, `tabular-nums` | Text 500 |

Не меньше 13 px; `line-clamp` 2 на карточках, 3 в шапке.

### Форма

Радиусы 12 (плитки) · 16 (постеры в рядах) · 20 (billboard, билет) ·
28 (шиты) · 999 (пилюли, кнопки, меню). Поля экрана 16, между карточками
10, между секциями 28. Тап-зоны ≥44 px.

**Стекло.** Не больше двух стеклянных слоёв на экране, альфа ≥ .72,
не анимируется. Фолбэк (`@supports not` / `.no-blur` по
`hardwareConcurrency ≤ 4` или `deviceMemory ≤ 3`) — surface 3.

**Фото.** Под нижним блоком текста скрим ≥ .65; верхняя метка лежит на своей
тёмной плашке; остальное фото не затемняем. Текст на фото всегда белый. Без фото — цветной блок цвета `poster` с иконкой.

## 4. Навигация

**Таб-бар.** Плавающая капсула: высота 56, ширина ≤ 300, по центру, отступ
снизу `12px + safe-area`, фон `tabbar`, обводка 1 px. Три вкладки:
Дом · Избранное · Кабинет. Только иконки 26 px в зоне 48×48, подписей нет;
`role="tablist"`, у каждой `aria-label`. Активная — `fill: #FFFFFF`, без
обводки; неактивные — `fill: none; stroke: #8F898C; stroke-width: 1.7`.
Смена — без анимации формы, haptic `selection`.

**Иконки** — файлы владельца, кладутся в `webapp/src/ui/icons/` как есть
(`currentColor`, viewBox 24): `home.svg` (залитый; неактивный — тот же
контур штрихом), `heart.svg`, `profile.svg` (активные — те же пути с
заливкой). Остальные иконки интерфейса — Lucide, stroke 1.7.

**Пилюля «Сегодня».** Если у гостя есть билет на событие сегодня —
стеклянная пилюля над меню (8 px выше): миниатюра постера 28 px,
«Сегодня · 23:00», название, иконка QR. Тап открывает экран билета сразу
на QR. Скрыта на экране события и на экране билета.

**Скрытие меню.** Меню скрыто на экране события, оплаты, ожидания,
результата и билета (там своя нижняя панель или «назад»).

## 5. Экраны

### Дом

Сверху вниз:
1. **Чипы-фильтры** по направлениям: «Все · Киновечер · Мастерклассы ·
   Книжный клуб» (стеклянные; выбранный — белый с чёрным текстом). Горизонтальный
   скролл.
2. **Лента дат**: 14 дней вперёд пилюлями «пн 13». Точка над днём, где есть
   событие; выбранный — белый. Тап фильтрует ряды; повторный тап снимает.
3. **Billboard**: ближайшее событие (или до 3, автосмена 6 с, точки
   пагинации; пауза при касании), высота = 0.9 × ширина, радиус 20.
   Метка «Киновечер · 18+» сверху слева на тёмной плашке, статус-пилюля
   сверху справа; слева снизу — подзаголовок-кикер («Уже в эту субботу»,
   «Сегодня в 20:00») цвета афиши с точкой и под ним название, скрим снизу
   только под текстом. Тап — экран события.
4. **Ряд «На этой неделе»**: постеры 16:9, ширина 82% экрана (виден край
   следующего), название и дата на картинке.
5. **Ряд «Скоро»**: постеры 4:5, ширина 40% экрана, название и дата под
   постером.
6. **Плашка брони** (если есть живая бронь): «Бронь ждёт оплаты · 08:12»
   стеклом над меню вместо пилюли «Сегодня».

**Статус-пилюли** (на постерах, rgba(0,0,0,.55) без blur, точка цвета
`poster`): «● Сегодня», «● Осталось 12», «Мест нет» (постер десатурирован).

**«Идут +N».** Стопка до 3 аватаров 22 px с белой обводкой 1.5 px + «+N»
на billboard и экране события. Показываем только аватары гостей, давших
согласие (`show_in_attendees`); остальные — в числе N. На этапе A — mock.

### Избранное

Сердечко на постере (правый верхний угол, стеклянный круг 36 px) и на
экране события. Список — сетка постеров 4:5 в 2 колонки, прошедшие
события — в конце, десатурированы. Хранение — Telegram `CloudStorage`
(ключ `fav`, массив id ≤ 100); бэкенд не нужен. Пусто: «Тут будут
сохранённые вечера» / «Жми сердечко на афише — соберём всё здесь».

### Экран события

- **Шапка**: постер на всю ширину, высота 4:5 от ширины, нижние 40% —
  градиент в #000; стеклянные круглые «назад» и сердечко сверху. На постере
  снизу: meta, название h1, «сб, 25 окт · 23:00».
- **Пилюли** под шапкой: возраст, дресс-код (если задан), «идут +N».
- **О вечере** — описание.
- **Где** — адрес строкой + «Построить маршрут» (ссылка в карты).
- **Билеты** — типы со счётчиками −/+ как в старой спеке.
- **Плашка покупки** — стеклянная панель снизу (`12px + safe-area`):
  слева «3 билета · 4 650 ₽» (или «от 1 500 ₽», пока 0), справа белая
  кнопка «Купить». Нуль билетов — кнопка ведёт к блоку «Билеты»; мест нет —
  кнопка заменяется на «Мест нет» серым. Загрузка — спиннер внутри кнопки,
  ширина фиксирована.
- Голосование вечера убрано.

> **Изменение относительно старой спеки:** MainButton Telegram больше не
> используется — его нельзя оформить в общем стиле. Нижняя панель своя на
> экранах события, ожидания и результата; поведение (блокировка, прогресс,
> `enableClosingConfirmation`) переносится на неё без изменений.

### Кабинет

Шапка: аватар и имя из Telegram, под ними счётчик «12 вечеров с нами».
Разделы списком (стеклянные строки 56 px):
1. **Мои билеты** — веер действующих билетов (см. §6), под ним
   «Прошедшие · N».
2. **Мои вечера** — горизонтальный ряд «оторванных» билетов-сувениров.
3. **Поддержка** — «Написать организатору» (ссылка в бота), «Как вернуть
   билет».
4. **Приватность** — переключатель «Показывать меня в списке гостей»
   (по умолчанию выключен).

### Оплата, ожидание, результат

Логика — как в старой спеке. Визуально: чёрный фон с ореолом цвета
события, крупный заголовок h1 по центру, нижняя панель с белой кнопкой.

## 6. Билет

**Карточка** — радиус 20, ширина экран − 48, фон `ticket paper`:
1. постер 16:10 сверху (без скругления снизу), на нём название и дата;
2. данные сеткой 2×2: «Гость / Дата / Вход / Билет» — подпись `muted`
   12 px, значение `ink` 15 px 500;
3. **перфорация**: пунктир 2 px `perforation` (штрих 6, пробел 5) с
   полукруглыми вырезами Ø22 по краям (маска `radial-gradient`, вырез
   прозрачный — виден фон экрана);
4. **корешок**: QR ≥ 240 px на белой подложке с полями 16, под ним
   короткий номер и «Билет 2 из 3».

**Несколько билетов** — веер: текущий по центру, соседние видны на 14% по
бокам, повернуты ±6° и уменьшены до .92, opacity .6. Свайп листает,
точки пагинации снизу.

**Состояния:** действителен — как выше; использован — корешок «оторван»
(см. анимации), поверх постера пилюля «Было · 25 окт», QR скрыт;
возвращён / передан / отменён — весь билет десатурирован, корешок без QR,
пилюля статуса словом. Яркость экрана билета не трогаем; QR и данные
кэшируются для офлайна (как раньше).

## 7. Анимации

Сдержанно, `prefers-reduced-motion` — всё мгновенно:
- смена цвета ореола — 400 мс ease-out;
- нажатие карточек и кнопок — scale .98, 120 мс;
- веер билетов — следует за пальцем, доводка 250 мс;
- отрыв корешка (первый показ использованного билета) — корешок съезжает
  вниз на 24 px с поворотом 4° и исчезает, 500 мс; один раз на билет.

## 8. Тексты (новый голос)

На «ты», тепло, лёгкий сленг, без эмодзи. Склонения, форматы дат и цен — как
в старой спеке. Ключевые строки:

| Где | Текст |
|---|---|
| Пустой Дом | «Пока тихо» / «Новых вечеров нет. Как появятся — маякнём в боте.» |
| Ожидание | «Бронь ждёт оплаты» / «Места за тобой ещё 08:42» |
| Успех | «Ты в деле!» / «Ждём в чт, 16 окт в 20:00. Копия билета уже в боте.» |
| Банк молчит | «Банк что-то задумался» / «Если оплата прошла, билет прилетит в бот. Страницу можно закрыть.» |
| Неуспех | «Оплата не прошла» / «Деньги не списаны. Бронь держим ещё 6 минут.» |
| Нет сети | «Нет связи» / «Проверь интернет. Купленные билеты никуда не денутся.» |
| Бронь истекла | «Бронь закончилась» / «Десять минут прошли — места вернулись в продажу.» |
| Мест меньше | «Мест стало меньше» / «Пока шёл выбор, осталось 2 места. Берём 2?» / «Берём 2» · «Изменить» |
| Пустые билеты | «Билетов пока нет» / «Выбери вечер на главной — билет появится здесь.» |
| Пустое избранное | «Тут будут сохранённые вечера» / «Жми сердечко на афише — соберём всё здесь.» |
| Использован | «Было · 25 окт» |
| Бот, за сутки | «Завтра, чт, 16 окт, в 20:00 — «Киновечер». У тебя 2 билета. Адрес: [адрес]. До встречи!» |
| Бот, за 3 часа | «Сегодня в 20:00 — «Киновечер». Через 3 часа ждём: [адрес]. Билет держи под рукой — на входе сканируем QR.» |

## 9. Изменения в данных и API

- `events.accent_color` (nullable, `#RRGGBB`) — ручной цвет афиши;
  отдаётся в `GET /events` и `GET /events/{id}`.
- `users.show_in_attendees` (bool, default false) +
  `PATCH /me {show_in_attendees}`.
- `GET /events/{id}` и список: `attendees: {count, avatars: [url ≤ 3]}` —
  только согласившиеся в `avatars`.
- Опросы: эндпоинты остаются, Mini App их не вызывает.

Этап A (визуал) — всё на mock-данных; миграции — в этапе бэкенда.

## 10. Компоненты

Новые: `TabBar` (3 иконки), `TodayPill`, `FilterChips`, `DateStrip`,
`Billboard` (+пагинация), `PosterRow` (вариант `wide` 16:9 / `tall` 4:5),
`StatusPill`, `AttendeesStack`, `FavButton`, `PosterHeader`, `BuyBar`,
`PaperTicket` (+ `TicketFan`), `Glow` (ореол), `ProfileHeader`,
`ListRow`, `Toggle`.

Переделываются: `Button` (primary белый, secondary стекло), `EventCard` →
`PosterRow`, `TicketCard`+`Pager` → `PaperTicket`+`TicketFan`,
`StatusScreen`, `EmptyState`, `ErrorState`.

Убираются из навигации: `Polls`, `PollOption` (файлы остаются).

`lib/posterColor.ts` — выбор цвета афиши (п. 3), чистая функция с тестами
на нормализацию HSL и фолбэки.

## 11. Тестирование

- Unit: `posterColor` (accent_color → извлечение → хэш; границы S/L),
  `CloudStorage`-избранное (добавить/убрать/лимит 100), веер (индекс,
  границы), выбор подзаголовка billboard («Сегодня», «Завтра», «В эту
  субботу»).
- Компоненты: TabBar (активная залита, `aria-selected`), TodayPill
  (показ только сегодня, скрытие на событии), BuyBar (0 / N / мест нет /
  загрузка), PaperTicket (все 4 состояния).
- Вручную: контраст текста на 10 реальных постерах (светлые, тёмные,
  пёстрые); `no-blur`; `prefers-reduced-motion`; крупный шрифт; экран 320 px.
