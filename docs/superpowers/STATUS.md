## Отложенные минорные замечания (финальное ревью)

- Плашка брони в афише застывает на 00:00 после истечения.
- CloudStorage: нужна проверка версии клиента (< 6.9). Сбой `storage.set` после `createOrder` показывает не тот диалог.
- Шаг размера длинного заголовка в герое; заголовок плитки 13 px — ниже пола 14 px.
- Контраст: прозрачность `.inactive` у билетов; фокус-рамка через `--accent` на светлой теме.
- «0 минут» и истечение брони не озвучиваются скринридером.
- QR: отступ 1 (в плане 2); плашка 292 px на экранах 320 px.
- Диалоги: «…или отменить?» без кнопки отмены, главная кнопка активна под диалогом, нет ловушки фокуса.
- `navigate(-1)` без истории; у ClaimScreen нет кнопки «назад».
- Повторный запуск снова применяет `start_param` (claim показывает «уже забрал») — на этапе Б claim должен быть идемпотентным для того же пользователя.
- Больше двух стеклянных слоёв на «Голосуем»; TabBar использует `max()` вместо 12px + safe-area; тема мигает один кадр; двойной `/me` при старте; жёсткие цвета в MockPay и подложке Dialog; у группы билетов «Игры» иконка кино.
