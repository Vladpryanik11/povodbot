# Повод — тексты входной группы бота

Голос: так пишет живой человек из клуба в личку. На «ты», от лица клуба — «мы».
Простые фразы, точки и запятые. Тире — редко, не больше одного на сообщение.
Не надо красивостей («вечера, на которые хочется прийти»), троек через запятую,
«жми кнопку ниже», «ждёт тебя». Слово «реклама» не используем. Эмодзи нет.

---

## 1. Описание бота (Bot description, до 512)

Своя часть ~150 символов, остальное под текст владельца.

```
Это бот клуба «Повод». Здесь можно посмотреть, какие у нас вечера, и купить билет. Сюда же придёт сам билет и новости, если что-то поменяется.

[ТЕКСТ О ДАННЫХ — впишет владелец]
```

## 2. Короткое описание (About, до 120)

```
Вечера клуба «Повод». Афиша и билеты.
```

## 3. Первый /start

С именем:

```
Привет, {name}! Это «Повод».

Все наши вечера и билеты в приложении, открывается кнопкой.
```

Без имени:

```
Привет! Это «Повод».

Все наши вечера и билеты в приложении, открывается кнопкой.
```

## 4. Повторный /start

```
Привет, {name}! Открывай, посмотри, что у нас скоро.
```

Без имени:

```
Привет! Открывай, посмотри, что у нас скоро.
```

## 5. Кнопки

```
Mini App:      Открыть Повод
Афиша в чате:  Афиша
Билеты:        Мои билеты
Поддержка:     Поддержка
Назад:         Меню
```

«Открыть Повод» — отдельной строкой сверху, под ней «Афиша» (покупка в чате, пока Mini App не принимает заказы), «Мои билеты» и «Поддержка» — парой внизу.

## 6. «Мои билеты»

Заголовок:

```
Твои билеты:
```

Пусто:

```
Билетов пока нет. Загляни в приложение, там афиша.
```

Кнопка под пустым состоянием: `Открыть Повод`

Строка билета: `{title}, {date} в {time}. {status}`

Статусы:

```
active / valid  ->  Действует
used            ->  Использован
cancelled       ->  Отменён
refunded        ->  Деньги вернули
```

## 7. «Поддержка»

```
Если что-то не так с билетом или оплатой, напиши нам: {contact}

Сразу укажи, на какой вечер билет, так быстрее разберёмся.
```

## 8. /stop

Убран по решению владельца (2026-10-11).

## 9. Команды для @BotFather

```
start - Открыть Повод
tickets - Мои билеты
help - Поддержка
```

## 10. Ответ на непонятный текст

```
Мы тут отвечаем только на кнопки. Афиша и билеты в приложении, а если есть вопрос, нажми «Поддержка».
```

## 11. Ошибки в router.py

Было: `Параметр /start слишком длинный: максимум 64 символа. Отправьте /start без параметра или воспользуйтесь корректной ссылкой.`

```
Что-то не так со ссылкой. Отправь просто /start.
```

Было: `Заказ создан. Готовим защищённую ссылку на оплату…`

```
Заказ есть. Сейчас пришлём ссылку на оплату.
```

Было: `Не удалось создать заказ. Откройте актуальную афишу и попробуйте ещё раз.`

```
Не получилось оформить заказ. Открой афишу заново и попробуй ещё раз.
```

Было: `Заказ создан, но платёж не удалось запустить. Обратитесь в поддержку клуба.`

```
Заказ есть, но оплата не запустилась. Напиши в поддержку, разберёмся.
```

## 12. Возвращалки (гость давно не заходил)

Стиль — пуши Whoosh и «Золотого Яблока»: коротко, с иронией над собой и над диваном, без давления.
Одна шутка на сообщение. Без родовых окончаний, без «скучаем по тебе!!!». Под каждым — кнопка `Открыть Повод`.
Если есть ближайший вечер — подставляем `{event}` и `{date}`, если нет — вариант без них.

### Две недели тишины

```
Диван, конечно, удобный. Но он с тобой не разговаривает. А у нас {date} «{event}».
```

```
Проверка связи. Мы всё ещё устраиваем вечера, ты всё ещё можешь прийти. Совпадение?
```

```
Сериал подождёт, он на паузе. Вечер — нет. Глянь, что у нас на этой неделе.
```

### Месяц тишины

```
Мы тут посчитали: месяц без «Повода». Звучит как название грустной песни. Давай исправим.
```

```
Если что, мы не обиделись. Просто поставили афишу на видное место.
```

```
Хорошие новости: повод выйти из дома найден. Плохие: он только до {date}.
```

### Два месяца и дольше (последнее, потом молчим)

```
Пишем в последний раз, честно. Дальше только если сам заглянешь. Афиша, если что, тут.
```

```
Мы не навязываемся. Просто оставим это здесь: {date}, «{event}». Всё, ушли.
```

### Бронь есть, а оплаты нет

```
Билет на «{event}» остался в корзине и смотрит на тебя с надеждой. Бронь держим до {time}.
```

```
До «{event}» остался один шаг, и он про оплату.
```

### Вечер уже завтра (у гостя есть билет)

```
Завтра «{event}». Билет в приложении, а от тебя нужно только прийти.
```
