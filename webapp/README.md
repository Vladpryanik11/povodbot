# «Повод» — гостевой Telegram Mini App

Этап A: все экраны гостя и дизайн-система «Стеклянный вечер» на мок-данных.
Бэкенд, бот и оплата Т‑Банка не подключены — их место занимает `MockApi`
(`src/api/mock/`), реализующий контракт `AppApi` из раздела 5 спеки
`docs/superpowers/specs/2026-10-10-povod-miniapp-guest-design.md`.

## Запуск

```bash
npm ci
npm run dev
```

Откройте `http://127.0.0.1:5173/` в ширине телефона (375–430 px). Вне
Telegram главная кнопка рисуется внутри страницы, тема берётся из системы.

| Адрес | Что показывает |
|---|---|
| `/#/` | афиша (первый запуск — приветствие) |
| `/#/events/e-film` | карточка с голосованием и покупкой |
| `/#/tickets` | билеты, QR, «Отправить другу» |
| `/#/polls` | голосования |

Сценарии мок-сервера задаются параметром до `#`:
`/?scenario=pay_fail#/events/e-film`.

| Сценарий | Поведение |
|---|---|
| `happy` | по умолчанию: оплата проходит |
| `pay_fail` | любая оплата отклоняется, бронь живёт |
| `pay_pending` | банк молчит; через минуту «Банк отвечает дольше обычного» |
| `late` | оплата пришла после брони — ручная сверка |
| `sold_out` | при оплате выясняется, что мест осталось 2 |
| `empty` | нет мероприятий, билетов и голосований |
| `offline` | нет сети: ошибки с «Повторить», билеты из кэша телефона |

Приветствие запоминается в `localStorage` (`povod.mock.welcome`); чтобы
увидеть его снова, очистите хранилище сайта.

## Проверки

```bash
npm run typecheck
npm test
npm run build
```

## Ограничения этапа A

- Данные живут в памяти вкладки и сбрасываются при перезагрузке.
- Страница оплаты — имитация (`#/mock-pay/<id>`), денег не касается.
- Постеры в `public/mock/` сгенерированы ffmpeg, это заглушки.
- Показ внутри Telegram требует HTTPS-адреса и кнопки меню бота; место
  размещения выбирает владелец.
